# Portfolio

Academic and personal projects in machine learning, computer vision, and optimization.

## Machine Learning Projects

- **Predicting Population Changes in Czech Municipalities** (`mlp - project.html`) — end-to-end CRISP-DM project forecasting demographic trends from 50 years of data.
- **Time Series Analysis: Tourist Accommodation Occupancy in Czechia** (`scr - project.html`) — R analysis and forecasting of accommodation-occupancy trends.
- **Sparse Embedding Compression for Recommender Systems** (`pml - paper.pdf`) — evaluation of TopK / Gated TopK sparsification in the CompresSAE framework.
- **Age-Appropriateness Classification of Czech Texts** (`mvi - paper.pdf`) — fine-tuned Czech RoBERTa for classifying child-appropriate text.

## Machine Vision

Jupyter notebooks from the Machine Vision (SVZ) course — SVZ01–SVZ04 — covering object-distance calculation, image segmentation, and projective measurement pipelines.

## Optimization

- **Advanced Heuristics for Weighted MAX-SAT** (`kop - project.pdf`) — simulated-annealing variant with adaptive mechanisms for weighted Boolean satisfiability.
