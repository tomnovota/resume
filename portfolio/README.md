# Portfolio

This directory contains a collection of projects, homework assignments, and reports from my academic studies in Machine Learning, Computer Vision, and Optimization.

## Directory Structure

### 1. Machine Learning Projects
A showcase of more extensive projects applying machine learning and statistical analysis techniques.

*   **Predicting Population Changes in Czech Municipalities** (`mlp - project.html`)
    *   A machine learning project focused on predicting demographic shifts using municipality data.
*   **Time Series Analysis: Tourist Accommodation Occupancy in Czechia** (`scr - project.html`)
    *   A statistical computing project using R to analyze and forecast occupancy trends in tourist accommodations.
*   **Project Reports**
    *   `pml - paper.pdf`: Personalized Machine Learning - Improved embeddings sparsification technique.
    *   `mvi - paper.pdf`: Transformer model used to classify the appropriateness of text for children.

### 2. Machine Vision Homeworks (`machine vision homeworks/`)
Jupyter notebooks from the Machine Vision (SVZ) course. These cover fundamental computer vision tasks:

*   **SVZ01 - SVZ04**: Implementation of algorithms for tasks such as calculating object distances (e.g., shortest distance between rectangles), image segmentation using thresholding, and other image processing techniques.

### 3. Optimization Projects (`optimization projects/`)
Contains work related to combinatorial optimization.

*   `kop - project.pdf`: Project report for the Combinatorial Optimization (KOP) course.
